# Appendix · Decision Log

**Purpose:** The engagement's memory. Every ruling is recorded once, here, and then reconciled back into the six documents it changes. If it is not in the log, it was not decided.

**When it is written:** Opened at kickoff. An entry is added the same day a ruling is made, never reconstructed later from meeting notes.

## Entry format

Each entry carries:

- **ID and date:** D-01, D-02, and so on, with the date of the ruling.
- **Decision:** One sentence, active voice, naming what is now true.
- **Options considered:** The real alternatives, including doing nothing where that was real.
- **Decided by:** The person or role with the authority to rule it.
- **Rationale:** Two to four sentences. Why this option, stated so that a reader in three months can disagree intelligently.
- **Documents updated:** Every document the ruling changed, listed by number. This field is the reconciliation step made visible. An entry with no documents listed means the ruling changed nothing on paper, which should be true rarely and said out loud when it is.

## Filled entry (fictional product: Tidepool)

**D-03 · 2026-09-14**
- **Decision:** The first release ships without guest access. Invited people join as Members or not at all.
- **Options considered:** (a) Guests with read-only access in release 1; (b) no guests in release 1, guests revisited after launch data exists; (c) guests delayed to a named release 2 with the permission work scheduled now.
- **Decided by:** Sponsor, on the engagement lead's recommendation.
- **Rationale:** The permission model doubles in size for a read-only guest role, and no current user evidence says guests are the blocker to adoption. Option (c) was rejected because scheduling design work for an unproven need spends the Phase 3 budget twice. The need, if real, will show up in launch feedback with names attached.
- **Documents updated:** 01 (OD-01 closed; PR-06 removed from release 1 scope), 05 (guest entity deferred, noted in section 8), 06 (Phase 3 scope reduced; decision point removed).
